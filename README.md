# Tarot Trumps Tracker

Application mobile-first pour suivre les atouts tombés pendant une partie de Tarot.

## Utilisation

Ouvrez `index.html` dans un navigateur (ou via GitHub Pages).

- Touchez un atout pour le marquer comme tombé (ou annuler).
- Les bouts (1, 21 et Excuse) sont mis en évidence.
- Le compteur et la barre de progression se mettent à jour en temps réel.
- L'état est sauvegardé localement (persiste après rafraîchissement).
- Bouton Réinitialiser avec confirmation.

Conçu pour une utilisation à une main sur téléphone pendant le jeu.
